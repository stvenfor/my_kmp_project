## ADDED Requirements

### Requirement: Mine root visual parity
Mine root header, stats, service grids, and menu rows SHALL match Flutter `module_settings` / Mine product visuals including icons and section structure.

#### Scenario: Menu icons present
- **WHEN** the user views Mine personal function or settings entry rows
- **THEN** icons and row chrome match Flutter assets/layout rather than text-only rows where Flutter uses icons

### Requirement: Settings screens visual parity
Settings and personalized settings pages SHALL match Flutter settings typography, row height, dividers, and trailing affordances.

#### Scenario: Settings list density
- **WHEN** the user opens Settings
- **THEN** row spacing, title/subtitle hierarchy, and chevrons match Flutter settings styling
