## 首页 UI 还原 + 底部 Tab 重构 + 资源同步 + Mock 手机号登录（KMP）

用户诉求（原文）：「现在首页的UI效果还原度很差，底部tab也需要重构，目前资源也没同步，需要优化。然后处理好登陆页面的手机号登陆，现在13400000000帐号无法登陆」
决策（AskUserQuestion）：Android 优先 / 保持 4 tab 只做视觉重构 / 移植 Flutter Mock 登录。

### 1. 手机号登录修复（13400000000）
- 根因：本地正则 `^1[3-9]\d{9}$` 完全匹配该号，**不是本地校验问题**；KMP 无 mock，`loginWithOtp` 直连 `127.0.0.1:8080`，后端未起时返回「账号未注册/验证码错误」。
- 新增 `feature/auth/.../MockAuthConfig.kt`：移植 Flutter `mock_auth_service.dart`（白名单 13400000000~4、OTP `123456`、展示名 测试甲~戊、脱敏 `134****0000`、非白名单提示语逐字一致）。
- `AuthRepository` 在 `loginWithPassword / sendPhoneOtp / loginWithOtp / register` 前加 mock 分流；`commitSession` 落本地会话，不触网。
- 开关：`useMockAuth = !platformIsReleaseBuild()`（debug 开、release 关）；Android 在 `MainActivity.onCreate` 用 `ApplicationInfo.FLAG_DEBUGGABLE` 覆盖为真实值。**OHOS 的 `platformIsReleaseBuild()` actual 恒 false → OHOS release 目前也会走 mock，属已知待修**。
- UI：`LoginOtpScreen` 的测试号提示、`LoginScreen` 的 otp 提示都按 mock 开关条件显示。

### 2. 资源同步
- `scripts/sync-flutter-assets.sh` 修了两处 bug：`FLUTTER_ROOT` 默认值写死 `/Users/mac/...` → 改 `$HOME/...`；`DEST` 指向已废弃的 `composeApp/src/commonMain/composeResources/drawable` → 改 `core/design/...`。
- 新增 `DRY_RUN=1` 模式（只打印将写入/新增/目录多出的文件，不落盘）。
- 新增 Phase 2：以 compose drawable 为基线**扇出**到 `iosApp/.../Assets.xcassets`（生成 imageset + Contents.json）与 `harmonyApp/.../base/media`，按 sha1 判断「新增/刷新」。
- 实测结果：compose 170 / iOS 171 / OHOS 172，`compose-ios` 与 `compose-ohos` 差集均为空。补齐的 34 个主要是二级页整页截图（mall_*/mine_*/video_*/wallet_body/pay_membership_body/classroom_*/music_*）。
- 结论：产品资源（home78/pay31/settings3/music2 = 114）此前已同步且脚本幂等、零改名；真正缺的是 iOS/OHOS 两份副本。

### 3. 底部 Tab 重构
- `feature/shell/MainBottomBar.kt` 从 M3 `NavigationBar/NavigationBarItem` 改为手写 Row，逐项对齐 Flutter `IosTabBar`：高 49、顶部 0.5 hairline@0.6（用 Box 叠加，避免栏体变 49.5）、每项药丸 44×28 圆角 14（选中 link@12%，200ms 动画）、图标 22、间隙 2、label 10sp w600/w400、未选色改回 `mute`(#888888)（原来误用 body #4D4D4D）、底部安全区包在背景里。
- 不做真实 backdrop blur：Flutter 是 blur(20) 叠在 95% 不透明的 #F2FFFFFF 上，视觉上几乎不可见，且 Compose 无跨端 backdrop filter 原语。

### 4. 首页还原（核心）
- 关键发现：`feature/home/HomeScreen.kt`（共享 895 行）与 `composeApp/androidMain/.../NativeJetpackHome.kt`(522) + `NativeJetpackHomeExtras.kt`(351) 是**三份重复实现**。已抽出 `feature/home/HomeSections.kt`（9 个区块），两侧只保留宿主（滚动/下拉刷新/签到弹窗）。`NativeJetpackHomeExtras.kt` 删除。
- 逐块按 Flutter `home_dashboard_widgets.dart` 对齐，主要修正：
  - **Banner**：原来贴 `home_banner_sot`（1356×347 预烤整图，缩放失真）→ 改为代码渲染：`home_banner_bg`(800×400，正是 picsum seed/banner 那张，此前被误判为死资源) + black@25% 暗化 + accent@55%→transparent 横向渐变 + 「朋友圈营销」22sp w700/-0.3 + 副标题 14sp white@85% + 白色「立即体验」CTA（radius 20，padding 16/8）。
  - **问候**：加 `statusBarsPadding()`，间距改 safeTop+16+24（原来共享版漏了安全区，文字顶到状态栏）。
  - **服务推荐**：原来用 `home_all_services_*` PNG（那是**全部服务二级页**的图标）→ 改为 Flutter 的彩色描边图标瓦片（accent@12% 圆角 12 + 22dp 图标），8 色轮转 link/violet/cyan/warning/pink/linkDeep/violet/ink。为此新增 `HomeStrokeIcons.kt`（10 个手写**描边** ImageVector，OHOS-safe，不用 material-icons-extended）。
  - **公司数据**：门店行「店/▾/⇄」文字符号 → 真图标（Storefront 16 / ArrowDown 20 / SwapHoriz 18）；tab 外 padding 4→3、选中加 0.5 描边；指标卡底色 CanvasSoft #FAFAFA；明细数值 16→18sp、底色 linkBgSoft@35%。
  - **联系汽车之家**：标题从卡内移到卡外，字号 17→18（sectionTitle），卡圆角 12→8，行高对齐 ListTile 72dp，分割线 indent 68。
  - **行业动态**：补右侧 96×72 缩略图占位，标题改 w500/lineHeight 21。
  - **入口卡**（投资策略/学习报告）：圆角 12→8。
  - **字体**：全站首次启用 `DemoFonts.Geist`（此前 Geist TTF 已打包但零引用），新增 `HomeSectionStyle` 承载 Flutter `HomeDashboardTheme` 的 largeTitle/sectionTitle/sectionLabel。
- `core/design/DemoColors` 补别名：CanvasSoft / LinkDeep / LinkBgSoft / Warning / Violet / Cyan / HighlightPink。
